Understanding the Classification Report
  • Class Labels (0 and 1):
    • 0: Represents patients predicted as not having heart disease.
    • 1: Represents patients predicted as having heart disease.
  • Precision: Of all patients predicted to have (or not have) heart disease, how many predictions were correct? High precision means fewer false alarms.
  • Recall: Of all actual cases, how many did the model identify correctly? High recall means fewer missed diagnoses.
  • F1-score: The harmonic mean of precision and recall. Useful when classes are imbalanced.
  • Support: The actual number of samples for each class in the test data (e.g., how many truly had or didn’t have heart disease).
  • Accuracy: The overall percentage of correctly predicted cases, across both classes.
  • Macro Average: The unweighted mean of precision, recall, and F1-score across all classes (treats each class equally).
  • Weighted Average: The average of precision, recall, and F1-score, weighted by the number of samples in each class.

Tip: Scores closer to 1.0 indicate better model performance.
